# 📝 Word Building Game

A fun and interactive **Word Building Game** built using **Python**, **Tkinter**, and **Pygame**. Players must continuously enter valid English words where each new word starts with the last letter of the previous word. The game includes multiple difficulty levels, a scoring system, sound effects, and a high score tracker.

---

## 🎮 Features

* Interactive GUI built with Tkinter
* Three difficulty levels

  * Easy
  * Medium
  * Hard
* Real time score tracking
* High score leaderboard
* Sound effects and background music
* Word validation
* Dictionary lookup for entered words
* Keyboard shortcuts
* Restart and Main Menu options

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/Siva-kumar-r16/word-buildin.git
```

Go into the project directory

```bash
cd word-buildin
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the game

```bash
python main.py
```

---

## 🎯 How to Play

1. Start the game.
2. Select a difficulty level.
3. Enter a valid English word.
4. Every new word must begin with the last letter of the previous word.
5. Repeated or invalid words end the game.
6. Earn one point for every correct word.
7. Try to beat your highest score.
